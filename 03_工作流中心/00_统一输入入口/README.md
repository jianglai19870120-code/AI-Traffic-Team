# AI流量团队统一输入入口

当前阶段先统一走本地文件入口，不接飞书。

原因：

- 你现在真正缺的是固定输入口
- 不是再多一个对话入口
- 如果本地输入口还没定死，先接飞书只会把混乱搬到飞书里

当前默认对话口径：

- 在 `AI流量团队` 项目里，正式业务需求默认先由小姜接收
- 你不需要时刻关心自己在调用哪个 Agent
- 先由小姜判断任务应该分配给哪个 Agent
- 具体调用哪个 Skill / 程序 / 工具，由负责 Agent 自己根据 `能力清单.md` 判断
- 这条规则是项目级默认入口，不是 Codex 全平台所有新对话的强制接管

## 你现在固定只用这 3 个入口

### 1. 爆款选题筛选入口

正式自动分类表：

- `02_资产中心/04_爆款选题库/01_科学创业选题表.md`
- `02_资产中心/04_爆款选题库/02_能力成长选题表.md`
- `02_资产中心/04_爆款选题库/03_赚钱财富选题表.md`
- `02_资产中心/04_爆款选题库/04_个人IP选题表.md`
- `02_资产中心/04_爆款选题库/05_AI科技选题表.md`
- `02_资产中心/04_爆款选题库/99_其他类型选题表.md`

规则：

- `爆款选题分类Skill` 只读取对标账号表里的 `视频信息` 列。
- `视频信息` 中 `#` 后内容视为话题标签，不进入选题。
- 分类表字段固定包含 `是否选用`，这一列默认留空，供你人工填写。
- `00_手动输入选题表.md` 是人工输入入口，自动脚本不读不写。
- `02_资产中心/04_爆款选题库` 现在就是正式资产目录，真实选题直接在这里维护。
- 手动输入选题表字段正式固定为：
  - `序号`
  - `文案结构`
  - `选题`
  - `正文时间`
  - `正文状态`
  - `成稿时间`
  - `成稿状态`
  - `视觉时间`
  - `视觉状态`

外部用户默认入口：

- `02_资产中心/04_爆款选题库/00_手动输入选题表模板.md`
- `02_资产中心/04_爆款选题库/样板-爆款选题分类表.md`

### 2. 原始资料输入口

文件：

- `02_资产中心/01_原始知识库/00_原始资料输入清单.md`

规则：

- 这里只录资料本身
- 不在这里绑定选题
- 不在这里判断进入哪条链路
- 这里只记录：资料标题、作者/来源主体、资料类型、原始资料文件路径、当前状态
- 书类资料直接放进原始知识库
- 如果不是 `md`，由小息调用 `原始资料标准化入库Skill` 转成正式 `md`

### 3. 爆款开头选择入口

正式文件：

- `02_资产中心/05_爆款开头库/00_爆款开头选中清单.md`

规则：

- 原始账号表不新增表内选择字段。
- 你只在外部选中清单里写 `博主名`、`视频信息` 或 `链接`。
- `爆款开头拆解Skill` 回到 `02_资产中心/03_对标账号库` 读取 `文案` 和 `视频信息`，生成 `BKxxx` 开头卡片。
- 开头卡片必须包含五句结构骨架和调用匹配规则，供后续文案生成 Skill 复刻。

外部用户默认入口：

- `02_资产中心/05_爆款开头库/00_爆款开头选中清单模板.md`
- `02_资产中心/05_爆款开头库/样板-爆款开头拆解.md`

### 4. 视觉配图输出入口

正式目录：

- `02_资产中心/08_视觉配图库/01_干货型配图`

规则：

- 当前视觉生成正式落点统一进入 `08_视觉配图库`
- `待生成视觉` 的统计口径仍以手动输入选题表里的 `视觉状态` 为准
- 视觉文件夹用于承接 `IP视觉PPT生成Skill` 的正式输出

## 当前建议

现在先不要接飞书机器人。

建议顺序：

1. 先把这 3 个本地入口用顺
2. 至少跑通 1 到 2 条真实链路
3. 再决定是否把小姜接到飞书

到那时候再接飞书，才是在放大一个已经清晰的流程。

## 小姜可直接理解的两种书类需求

### 1. 你已经有一本要拆的书

你可以直接对小姜说：

- “这本书帮我拆一下”
- “这份原始资料先帮我转成 md”

小姜会先区分：

- 如果资料还不是正式 `md` -> 小姜分配给小息，由小息判断调用标准化入库能力
- 如果资料已经是正式 `md` 且通过原始资料入库审核 -> 小姜分配给小拆，由小拆判断调用 `书籍内容模块拆解Skill`

### 2. 你已经有正式选题或想选用某条对标选题

你可以直接对小姜说：

- “这条爆款选题我想选用”
- “把这条对标记录加入爆款开头选中清单”
- “新增一个手动选题：XXX”

小姜会先判断它属于爆款选题筛选、手动选题输入还是爆款开头选择，不会再反向触发旧总选题表链路。
