这是一套围绕内容拆解、结构沉淀、文案生成和视频配图的生产系统。

当前正式主结构：

1. `01_内容模块大师`
2. `02_爆款结构大师`
3. `03_爆款文案大师`
4. `05_视频配图大师`

## 当前正式口径

### 01_内容模块大师

已经切换为新版模块库结构：

- `01_输入库`
- `02_模块库`

正式资产只保留：

- `金句模块`
- `故事模块`
- `误区模块`
- `步骤模块`

其中：

- `故事 / 误区 / 步骤` 是原子文件
- `金句模块` 按一级分类聚合
- `金句模块` 在一级分类下按二级分类分组
- `步骤模块` 标题必须是疑问句
- 如果点名拆某一本书，默认同步产出 `金句 / 故事 / 误区 / 步骤`

### 03_爆款文案大师

默认只从 `01_内容模块大师/02_模块库` 取材，不再读取旧处理库或旧输出库。
