# 讲干货-AI流量团队 Skill 接入说明

## 1. 当前正式 Skill 清单

内容模块侧：

- `拆书金句模块Skill`
- `拆书故事模块Skill`
- `拆书误区步骤Skill`

爆款结构侧：

- `爆款结构skill`

爆款文案侧：

- `爆款文案生成skill`

视频配图侧：

- `ip-ppt-skill`

## 2. 边界关系

- `拆书金句模块Skill`：服务 `01_内容模块大师/02_模块库/01_金句模块`
- `拆书故事模块Skill`：服务 `01_内容模块大师/02_模块库/02_故事模块`
- `拆书误区步骤Skill`：服务 `01_内容模块大师/02_模块库/03_误区模块` 和 `04_步骤模块`
- `爆款结构skill`：服务 `02_爆款结构大师`
- `爆款文案生成skill`：服务 `03_爆款文案大师`
- `ip-ppt-skill`：服务 `05_视频配图大师`

## 3. 单本书默认拆解链路

如果用户是对 `01_输入库` 中某一本书或某一篇内容发起拆解，默认不是单独调用某一个模块 skill，而是同步调用整条内容模块链路：

1. `拆书金句模块Skill`
2. `拆书故事模块Skill`
3. `拆书误区步骤Skill`

最终一次性沉淀四类结果：

1. `金句`
2. `故事`
3. `误区`
4. `步骤`

当前正式落点统一为 `02_模块库`。

## 4. 已废弃口径

以下内容不再作为正式入口：

- `整篇独立拆解模块skill`
- `02_处理库`
- `03_输出库`
- 旧按书聚合的 `方法论模块`
- 旧按书聚合的 `故事模块`

## 5. 新电脑安装建议顺序

1. `拆书金句模块Skill`
2. `拆书故事模块Skill`
3. `拆书误区步骤Skill`
4. `爆款结构skill`
5. `爆款文案生成skill`
6. `ip-ppt-skill`
