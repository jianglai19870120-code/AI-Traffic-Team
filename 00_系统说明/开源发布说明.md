# 开源发布说明

这个仓库采用的是：

- 源码公开
- 可免费学习和安装
- 禁止未经授权的商用
- 禁止转售
- 禁止重新包装成别人的产品

这不是宽松型开源协议，不走 MIT 或 Apache-2.0。

公开层保留：

- Agent 架构
- 工作流说明
- Skill
- 通用脚本
- 空模板
- 少量样板
- 公开发布检查工具

当前阶段说明：

- 现在只锁定发布骨架
- 现在不做完整公开可安装发布
- 首次正式发布要等主工作流跑通、Skill 边界稳定后再做

作者私有层保留：

- 真实原始知识
- 真实内容模块
- 真实文案
- 真实视觉页
- 真实选题和复盘

`_private/` 是作者本地私有层，不进入 GitHub。外部用户安装后，默认不需要使用 `_private/`，他们的资料、模块、文案和视觉结果写入正常工作链路，例如 `02_资产中心/...`。

公开发布包的完整边界见：

`00_系统说明/公开发布包说明.md`
