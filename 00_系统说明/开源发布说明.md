# 开源发布说明

这个仓库采用的是：

- 源码公开
- 可免费学习和安装
- 禁止未经授权的商用
- 禁止转售
- 禁止重新包装成别人的产品

这不是宽松型开源协议，不走 MIT 或 Apache-2.0。

正式主链保留：

- Agent 架构
- 工作流说明
- Skill
- 通用脚本
- 公开发布检查工具

当前阶段说明：

- 现在走的不是模板包模式，而是真实主链公开模式
- 只有少量本地隐藏目录不进入 GitHub
- 正式资产默认直接维护在 `02_资产中心/...`
