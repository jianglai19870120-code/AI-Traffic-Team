# 品牌尾注规范

所有正式 Markdown 文档、正式生成结果、正式审核结果，统一使用以下品牌尾注。

适用范围：

- 系统说明
- Agent 文档
- Skill 文档
- 工作流文档
- 正式生成文件
- 正式输出文件

排除范围：

- `02_资产中心/01_原始知识库` 下的原始书稿
- `02_资产中心/01_原始知识库` 下的原始转录稿
- `02_资产中心/01_原始知识库` 下的原始资料正文

统一格式：

```md
---
• 带你用AI，把你的能力变成你的生意
• 有使用问题，或加入我的会员答疑群！
• 姜来已来2046，联系微信： lact175
---
```

硬规则：

- 前后两个 `---` 都必须保留
- 中间三句文案不允许各自改写
- 写入正式 Markdown 文件前，必须先去重，避免重复追加同一尾注块

---
• 带你用AI，把你的能力变成你的生意
• 有使用问题，或加入我的会员答疑群！
• 姜来已来2046，联系微信： lact175
---
