# 公开白名单与私有黑名单

## 公开白名单

这些内容可以进入公开仓库：

- Agent 架构
- 工作流说明
- Skill
- 通用脚本
- 空模板
- 联系入口模板
- 少量脱敏样板
- 安装契约和发布检查脚本
- 公开发布包说明

## 私有黑名单

这些内容不能进入公开仓库：

- `_private/`
- 旧三条历史工作区
- 真实原始知识
- 真实内容模块
- 真实选题
- 真实成稿
- 真实视觉页
- 真实复盘
- 作者个人环境文件
- 旧母本完整业务内容

## 外部用户写入规则

外部用户从 GitHub 下载后，默认直接使用正常链路目录工作，不需要把内容写进 `_private/`。

默认写入位置：

- 原始资料：`02_资产中心/01_原始知识库`
- 内容模块：`02_资产中心/02_内容模块库`
- 对标账号字段模板：`02_资产中心/03_对标账号库`
- 爆款选题样板：`02_资产中心/04_爆款选题库`
- 爆款开头样板：`02_资产中心/05_爆款开头库`
- 视觉：`02_资产中心/06_视觉库`
- 复盘：`02_资产中心/07_复盘库`

`_private/` 只是作者本地私有层。外部用户如果也想隔离自己的私有资产，可以自行创建，但不是默认要求。

只有当主工作流跑通、Skill 合并稳定、公开样板准备好后，才进入第一次正式发布准备。
