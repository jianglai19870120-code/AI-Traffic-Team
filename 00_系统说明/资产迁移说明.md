# 资产迁移说明

当前根目录采用的是“公开层 + 作者私有层”的双层结构。

公开层保留：

- 正式 Skill
- Agent 合同
- 工作流说明
- 通用脚本
- 空模板
- 少量脱敏样板

作者私有层保留：

- 真实原始知识
- 真实内容模块
- 真实文案
- 真实视觉页
- 真实选题与复盘

作者本机迁移规则：

- 真实业务资产统一迁入 `_private/`
- 公开层只保留帮助他人理解结构的最小样板
- 旧母本目录未来可删，但私有资产层长期保留

外部用户安装规则：

- 外部用户不需要使用作者的 `_private/`
- 外部用户自己的资料、模块、文案和视觉结果默认写入正常链路目录
- 如果外部用户也想把自己的真实资产和公开仓库隔离，可以自行创建 `_private/`
