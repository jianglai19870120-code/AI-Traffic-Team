# 公开发布包说明

这个文件定义 AI流量团队 上传 GitHub 时的正式公开口径。

## 一句话结论

当前仓库采用单主链模式。

公开仓库默认同步真实正式主链：

- `00_系统说明`
- `01_Agent系统`
- `02_资产中心`
- `03_工作流中心`
- `10_Skills武器库`
- `tools`

只有少量本地隐藏目录不进入 GitHub，例如工作纪实、工作纪实模块和运行记录目录。

## 发布流程

固定流程：

1. 在工作母体 `E:\AI流量工厂` 修改
2. 运行 `tools/check_public_release.ps1`
3. 运行 `tools/prepare_public_release.ps1`
4. 检查 `E:\AI流量工厂-public`
5. 在 `E:\AI流量工厂-public` 执行 `git add / commit / push`

`prepare_public_release.ps1` 负责：

- 同步正式主链
- 排除本地隐藏目录
- 排除运行缓存和临时文件
- 保留正式资产、说明、Skill 和工具
- 调用公开发布检查

它不负责直接推送 GitHub。

## 发布前必须通过的检查

- 本地隐藏目录没有进入公开发布包
- 旧双轨路径没有残留在现役说明和脚本里
- 没有作者本机绝对路径依赖
- 没有缓存文件、运行产物和临时目录混入
- 外部用户下载后可以直接按正式主链开始使用
