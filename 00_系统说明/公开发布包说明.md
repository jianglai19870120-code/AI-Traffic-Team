# 公开发布包说明

这个文件定义 AI流量团队未来上传 GitHub 时的公开发布口径。

正式名称建议使用“公开发布包”，不要叫“上传文件”。

- “上传”只是把仓库推到 GitHub 的动作。
- “公开发布包”才是别人下载、安装、学习和复用时实际接触到的成品边界。

## 一句话结论

`_private/` 是作者本地私有层，不进入 GitHub。

外部用户安装 AI流量团队以后，不需要把自己的内容写进 `_private/`。他们默认直接使用正常工作链路：

- `02_资产中心/01_原始知识库`
- `02_资产中心/02_内容模块库`
- `02_资产中心/03_对标账号库`
- `02_资产中心/04_爆款选题库`
- `02_资产中心/05_爆款开头库`
- `02_资产中心/06_生成正文库`
- `02_资产中心/07_润色成稿库`

如果外部用户也想把自己的真实资产和公开仓库隔离，可以自己创建 `_private/`，但这不是系统默认要求。

项目级默认入口说明：

- 外部用户进入 `AI流量团队` 项目后，默认先按 **小姜** 入口理解正式业务需求
- 用户不需要先知道 Agent 名字，也不需要先学会调 Skill
- 这条规则由项目根目录 `AGENTS.md` 定义，并由现有 Agent 文档和 Skill 合同共同落实
- 这里说的是**项目级默认入口**，不是 Codex 全平台所有新对话的强制接管

## 公开发布包包含什么

公开发布包只保留能让别人理解、安装和复用系统的内容：

- Agent 系统骨架
- Agent 输入合同、输出合同、调用规则
- Skill 武器库结构
- 工作流说明
- 输入输出模板
- 脱敏样板
- 发布检查工具
- 公开安装和使用说明

## 公开发布包不包含什么

公开发布包不能包含你的真实业务资产：

- `_private/`
- 旧三条历史工作区
- 真实书籍资料
- 真实播客原文
- 真实对标视频原文
- 真实内容模块
- 真实选题
- 真实机器文案
- 真实成品文案
- 真实视觉图
- 真实账号数据
- 真实复盘数据
- 真实小姜工作台

## 规则同步原则

系统规则不能只写在作者私有层。

- 系统规则、Agent 原则、Skill 调用边界、审核标准、工作流原则必须保存在公开层正式文档中。
- `_private/` 只保存作者本地真实资产、执行记录和外部来料，不作为规则的唯一来源。
- 如果某条规则只写在 `_private/`，公开仓库用户将无法继承这条规则，因此不视为正式规则。
- 后续任何规则修正，都必须同步检查公开层文档是否需要更新。

小姜工作台规则：

- 小姜真实工作台属于作者真实生产状态，默认写入 `_private/agent_records/01_小姜-CEO助理Agent/`
- 每次调用小姜工作台时，除了刷新私有真实工作台，还必须自动执行一次公私模板同步
- 公私模板同步由 `tools/build_xiaojiang_dashboard.py` 触发，并调用 `tools/sync_public_templates.py`
- 公开层只保留工作台模板和说明，不保留真实待办、真实选题状态、真实审核状态或真实资产数量
- 公有层的原始资料输入清单模板、对标账号字段模板、爆款选题样板、爆款开头选中清单模板和工作台模板，都要跟着这次同步自动覆盖更新
- 工作台中非 md 文件不等于残留；只有“已转 md 且审核通过后仍未删”的旧原文件才叫残留

## 作者模式

作者模式指姜来已来自己在本机继续建设和生产 AI流量团队。

作者模式下：

- 外部来料可以放在 `_private/00_外部来料区/...`
- 真实业务资产可以放在 `_private/` 或被 `.gitignore` 排除
- 发布前只把框架、模板、说明、Skill 和脱敏样板留在公开层
- `_private/` 永远不作为公开发布内容

当前作者本机的电子书来料区固定为：

`_private/00_外部来料区/电子书/`

这个路径只服务作者本机，不要求外部用户也拥有同名目录。

## 外部用户安装模式

外部用户从 GitHub 下载 AI流量团队以后：

- 不需要使用作者的 `_private/`
- 不需要把内容重新放到私有层
- 默认直接在正常链路目录里录入自己的资料、选题、文案和视觉结果
- 如果他们自己也要保护私有资产，可以自行创建 `_private/`

外部用户的默认写入位置：

| 资产类型 | 默认写入位置 |
| --- | --- |
| 原始资料 | `02_资产中心/01_原始知识库` |
| 内容模块 | `02_资产中心/02_内容模块库` |
| 对标账号字段模板 | `02_资产中心/03_对标账号库` |
| 爆款选题样板 | `02_资产中心/04_爆款选题库` |
| 爆款开头样板 | `02_资产中心/05_爆款开头库` |
| 正文方案 | `02_资产中心/06_生成正文库` |
| 润色成稿 | `02_资产中心/07_润色成稿库` |

## 发布准备工具

公开发布包准备工具建议固定命名为：

`tools/prepare_public_release.ps1`

它负责：

- 生成临时公开发布目录
- 只复制公开白名单
- 排除 `_private/`
- 排除旧三条历史工作区
- 排除真实业务资产
- 保留模板、说明、样板和工具
- 调用公开发布检查脚本

它不负责把仓库上传到 GitHub。

## 发布前必须通过的检查

正式发布前必须确认：

- `_private/` 没有进入公开发布包
- 旧三条历史工作区没有进入公开发布包
- 公开层没有真实业务资产
- 公开层没有本机绝对路径依赖，例如旧的本机电子书盘符
- 外部用户不会被说明文档误导去使用作者私有层
- 外部用户可以直接从正常链路目录开始使用
