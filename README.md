# AI流量团队

带你用AI，把你的能力变成你的生意。

这是一个围绕 `Agent + Skill + 内容资产 + 工作流` 搭建的 AI流量团队。

项目级默认入口说明：

- 在 `AI流量团队` 项目内，正式业务需求默认先由 **小姜** 接收和判断
- 用户不需要先学习唤醒词，也不需要自己判断该找哪个 Agent
- 小姜只负责理解需求、判断任务类型、分配岗位、回收结果和最终汇报
- 具体执行规则仍以 `01_Agent系统`、`03_工作流中心`、`10_Skills武器库` 和 `00_系统说明` 为准
- 这个默认入口是**项目级规则**，不是 Codex 全平台所有新对话的强制接管

当前公开仓库定位：

- 源码公开
- 可免费学习和安装
- 支持持续更新
- 禁止未经授权的商用
- 禁止转售
- 禁止重新包装成别人的产品

新正式工作入口：

- `AGENTS.md`
- `00_系统说明`
- `01_Agent系统`
- `02_资产中心`
- `03_工作流中心`
- `10_Skills武器库`
- `tools`

项目现在采用单主链：

- 正式资产和规则默认直接写入现役主链
- 主要工作目录就是 `01_Agent系统`、`02_资产中心`、`03_工作流中心`、`10_Skills武器库`、`tools`
- 只有少量本地隐藏目录不进入 GitHub，例如工作纪实、工作纪实模块和 Agent 运行记录

外部用户安装后，默认直接使用正常链路目录，例如 `02_资产中心/...`。

如果你是第一次使用公开仓库，建议按这条路径开始：

1. 先看 `AGENTS.md`
2. 再看 `00_系统说明`
3. 然后根据你的任务进入 `02_资产中心`、`03_工作流中心` 或 `10_Skills武器库`

建议阅读顺序：

1. `AGENTS.md`
2. `00_系统说明/README.md`
3. `00_系统说明/公开发布包说明.md`
4. `00_系统说明/开源发布说明.md`
5. `00_系统说明/Agent总览.md`
6. `03_工作流中心/01_短视频主工作流/README.md`
7. `10_Skills武器库/README.md`
