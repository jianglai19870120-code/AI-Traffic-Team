# 播客内容模块拆解Skill

这是一个可公开安装的播客内容模块拆解 Skill。它不依赖固定工作区，调用时必须明确提供原文文件和输出根目录。

它会读取一篇播客字幕、访谈稿、博客或长视频原文，完成两类输出：

1. 生成一份高传播力的 `00-推荐理由.md`；
2. 按“总命题 -> 主题板块 -> 高密度分支观点金句 -> 2到4个结构化拓展点”重组全文内容模块，并把这些材料写得更适合下游直接拿去讲。

最终输出结构：

```text
原内容标题/
├── 00-推荐理由.md
├── 00-观点总览.md
├── 01-观点类型名.md
├── 02-观点类型名.md
└── ...
```

推荐理由固定包含：

- **一句话推荐**
- **为什么这篇内容值得听**（3条）
- **为什么这个作者或嘉宾值得听**（3条）
- **为什么现在值得听**（3条）

观点总览固定包含：

- **原内容标题**
- **原始文件**
- **观点类型总数**
- **一句话概括整篇内容**
- **观点类型目录与分支观点数量**

每个观点类型文件统一包含：

- **观点类型名称**
- **该类型的一句总述**
- **该类型下的全部分支观点**

每条分支观点统一包含：

- **一句话观点金句**
- **一组 2 到 4 个结构化拓展点**

默认拆解口径：

- 优先尊重原文真实话题推进，再归成主题板块；
- 不预设固定板块数，不为了“看起来完整”硬拆板块；
- 长播客默认按 `20-30 条` 分支观点的密度去提炼；
- 高密度主要体现在“更敢拆独立判断”，不是把一个上位主题反复换名。
- 每条观点下面默认写 `2-4` 个拓展点，不强制补满 3 点；
- 拓展标签默认按观点自适应选择，如 `误区 / 步骤 / 判断 / 反常识点 / 关键动作`。
- 金句和拓展点都要尽量写得更像能直接讲出来的话，而不是说明文备注。
- 语气默认保持冷静、坚定、有判断力、有未来感，不喊口号。

推荐理由允许使用原文与全网公开资料：

- 内容价值主要依据原文；
- 人物背书需要核实当前身份、代表成就和一线经验；
- “为什么现在值得听”需要核实近期行业变化；
- 写法要激进、笃定、博眼球，但不得编造事实。

完成后会保留完整的标题文件夹，并使用校验脚本检查推荐理由、观点总览和观点类型文件的完整性。除非用户明确提出，否则不会生成 ZIP 或其他压缩包。

## 安装

优先把整个 `播客内容模块拆解Skill` 目录直接安装到 Codex 的本地 skills 目录中。

不要只复制 `SKILL.md`，因为模板、规则、示例和校验脚本需要一起保留。

## 推荐调用方式

```text
调用“播客内容模块拆解Skill”，完整读取这份原始字幕。

原文路径：<原文文件绝对路径>
输出根目录：<输出目录绝对路径>

先生成 00-推荐理由.md。推荐理由要适合短视频传播，表达激进、笃定、有紧迫感；人物背书和最新时机需要联网核实，但不得虚构事实。

再按“总命题 -> 主题板块 -> 高密度分支观点金句 -> 结构化拓展点”的新逻辑重组全文观点。
每个观点类型生成一个独立 MD 文件，不再按单观点逐条拆成七模块。

板块数量要尊重原文真实结构，不机械凑固定数量；但长播客的分支观点默认要拆到高密度，通常在 20 到 30 条之间。
每条观点先立住一句金句，下面不要再写一整段为什么，而是围绕这句金句写 2 到 4 个结构化点；这些点不能重复解释标题本身，要往下展开误区、步骤、判断、反常识或动作。
金句要更像能直接开口讲的话，拓展点也要更顺口、更像推进句，而不是分析备注。

建立以原内容标题命名的文件夹，生成 00-观点总览.md，校验完成后直接保留完整输出文件夹。
```

更简短的调用方式：

```text
用“播客内容模块拆解Skill”处理这个文件，生成推荐理由、观点总览和观点类型文件。
```

## 文件说明

- `SKILL.md`：核心执行规则；
- `agents/openai.yaml`：Codex UI 展示信息与默认调用句；
- `references/viewpoint-classification.md`：总命题、主题板块与高密度分支观点识别规则；
- `references/quality-checklist.md`：质量检查规则；
- `references/recommendation-writing-rules.md`：推荐理由的研究与传播写法；
- `00-推荐理由.md`：推荐理由正式产物；
- `00-观点总览.md`：观点总览正式产物；
- 观点类型文件：按总命题下的观点分支正式落库；
- `examples/example-01.md`：观点类型文件示例；
- `examples/recommendation-example.md`：高传播力推荐理由示例；
- `examples/output-tree.md`：输出目录示例；
- `scripts/validate_output.py`：输出结构校验脚本；
- `sample-prompts.md`：常用调用提示词；
- `anti-patterns.md`：常见错误示例。
