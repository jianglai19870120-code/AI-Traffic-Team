# Skill 公开状态矩阵

当前这张表定义各 Skill 的正式公开状态。标记为 `可公开安装` 的 Skill 必须通过合同、依赖、安装副本和输出校验。

| Skill | 当前归属 | 当前状态 | 主要原因 | 首发前动作 |
|---|---|---|---|---|
| 原始资料标准化入库Skill | 小息 | 可公开安装 | 原始资料标准化正式入口 | 保持清单、文件命名和入库审核一致 |
| 书籍内容模块拆解Skill | 小拆 | 可公开安装 | 整本书内容拆解总入口 | 保持总入口文档、执行器、审核链一致 |
| 播客内容模块拆解Skill | 小拆 | 可公开安装 | 独立安装，用户显式提供原文与输出目录 | 保持输出校验器通过 |
| 工作纪实内容模块拆解Skill | 小拆 | 仅内部使用 | 真实工作纪实原文和模块不进入 GitHub | 保持本地隐藏目录说明和执行器一致 |
| 爆款开头拆解Skill | 小镜 | 可公开安装 | 已完成统一入口，开头卡片经小审后进入正式主链 | 保持说明、执行器、卡片合同一致 |
| 爆款选题分类Skill | 小策 | 可公开安装 | 将对标账号选题分类并同步双入口清单 | 保持分类规则、正式字段合同和审核报告一致 |
| 爆款开头成稿生成Skill | 小写 | 可公开安装 | 读取正文方案后按 BK 卡片生成最终成稿 | 保持十列清单、输入路由和成稿合同一致 |
| 得到大脑工作纪实同步Skill | 小息 | 仅内部使用 | 依赖用户自己的得到大脑 OpenAPI 配置，真实数据进入工作纪实隐藏目录 | 对外保留配置说明，不保留密钥 |
| 干货型文案生成Skill | 小写 | 可公开安装 | 正文方案中间层，不生成开头 | 保持十列清单和机器文案审核一致 |
| 播客爆款文案生成Skill | 小写 | 可公开安装 | 独立安装，五项输入显式提供 | 保持输出校验器通过 |
| IP视觉PPT生成Skill | 小图 | 可公开安装 | 运行产物不进入 Skill 源目录 | 保持运行产物排除和公开入口一致 |

说明：

- `可公开安装`：合同已锁定，可同步到 Codex 安装目录并对外发布
- `仅内部使用`：合同可公开说明，但不承诺外部安装和真实数据发布
