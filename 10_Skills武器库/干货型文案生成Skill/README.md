# 干货型文案生成Skill

当前版本只生成正文方案，不生成开头。

输入入口：

- `_private/assets/04_爆款选题库/00_手动输入选题表.md`

模块来源：

- 优先：`_private/assets/02_内容模块库/99_工作纪实模块`
- 补足：`_private/assets/02_内容模块库/01_干货型内容模块`

输出目录：

- `_private/assets/06_生成正文库/01_干货型文案`

输出规则：

- 文件名：`选题_YYYY-MM-DD_HH-mm-ss.md`
- 文件内 H1：与文件名主体一致
- 标题下固定写 `文案结构：干货型`
- 只输出一条主线
- 只输出一张四列表
- 表格字段：`序号 / 逻辑关系 / 选用模块 / 对应来源`
- 固定 11 行：误区1、误区2、过渡句、步骤1、步骤2、步骤3、过渡句、步骤1、步骤2、步骤3、金句收口
- 两个误区点可以来自不同模块
- 两组三步模块可以来自不同模块
- 第一组步骤共同解决一个问题，第二组步骤共同解决另一个问题
- 两组问题之间必须递进，整体逻辑和每组内部子逻辑都要成立
- 两条过渡句不写来源

本 Skill 不读取爆款开头库，不输出 `爆款开头复刻`，不输出旧三方案，不输出旧润色列。

当前定位是“正文方案中间层”。

干货型正文方案生成完成后，后续由 `爆款开头成稿生成Skill` 继续读取 `06_生成正文库` 和 `05_爆款开头库`，生成最终口播成稿。

审核规则：

- 正文方案生成后，必须立刻调用小审的 `audit_machine_drafts.py`
- 审核通过后，才能把手动输入选题表回写为 `生成状态=已生成`
- 审核退回时，必须回写为 `生成状态=退回修改`
