# 工作纪实内容模块拆解Skill

小拆使用本 Skill，直接读取私有工作纪实原文，把其中真实存在的金句、误区、步骤拆成可被正文生成链路调用的原子内容模块。

输出固定进入：

`02_资产中心/02_内容模块库/99_工作纪实模块`

内部结构固定为：

- `01_金句模块/工作纪实金句模块.md`
- `02_误区模块/工作纪实_错误观点：xxx.md`
- `03_步骤模块/工作纪实_xxx怎么做.md`
- `05_模块索引/模块索引.jsonl`
- `99_历史处理记录`

本 Skill 不生成选题、不生成文案；它只负责把真实工作记录沉淀成可复用模块。

固定原则：

- 有就拆，没有就不拆。
- 不靠推测补齐误区或步骤。
- 某篇工作纪实可以只产出金句，也可以什么都不产出，只在执行记录里说明原因。
