# 爆款开头卡片

- 开头编号：BK-SAMPLE-001
- 博主名：样板博主
- 选题：25年下半年赚点小钱有哪些机会

### 1. 原文前5句

1. 如果你想在25年下半年赚点小钱，有哪些机会和方法？
2. 这条视频我简单分享一下。
3. 我先问你个问题，你觉得赚钱这个事情主要是靠能力，还是靠运气？
4. 比如说，如果你在05年的时候就买房，你觉得能不能赚到钱？
5. 能，那如果你在08年的时候做淘宝，能不能赚钱？

### 2. 逐句拆解

|句子|原文|核心功能|写作结构|
|-|-|-|-|
|第1句|如果你想在25年下半年赚点小钱，有哪些机会和方法？|利益承诺|明确时间＋低门槛结果＋机会方法预告|
|第2句|这条视频我简单分享一下。|降低防备|弱化说教＋聊天式内容预告|
|第3句|我先问你个问题，你觉得赚钱这个事情主要是靠能力，还是靠运气？|认知提问|目标结果＋两个认知选项＋直接提问|
|第4句|比如说，如果你在05年的时候就买房，你觉得能不能赚到钱？|案例引入|历史时间节点＋具体机会＋结果追问|
|第5句|能，那如果你在08年的时候做淘宝，能不能赚钱？|连续确认|确认上一答案＋第二历史案例＋继续追问|

### 3. 五句推进逻辑

> 利益承诺 → 降低防备 → 认知提问 → 案例引入 → 连续确认

### 4. 五句结构骨架

1. 提出一个当下相关的低门槛利益问题
2. 用聊天式表达降低说教感
3. 抛出一个认知二选一问题
4. 列举第一个历史机会并追问结果
5. 确认上一答案，再列举第二个历史机会继续追问

句式模板：

1. 如果你想在【时间范围】获得【低门槛结果】，有哪些【机会或方法】？
2. 这条视频我简单分享一下。
3. 我先问你个问题，你觉得【目标结果】主要靠【选项A】，还是靠【选项B】？
4. 比如说，如果你在【历史时间节点1】做了【具体机会1】，你觉得能不能获得【结果】？
5. 能，那如果你在【历史时间节点2】做了【具体机会2】，能不能获得【结果】？

### 5. 适合承载的论证方式

> 历史案例＋连续追问

### 6. 调用匹配规则

适合的新正文：

> 正文核心结论需要靠多个历史机会、历史案例或同类案例连续证明。

需要具备的素材条件：

- 至少有两个可以成立的案例
- 案例之间具有同一个证明方向
- 案例可以通过“能不能”“是不是”等方式连续追问
- 案例能共同证明正文核心结论

不适合的新正文：

- 正文没有案例
- 只有一个孤立案例
- 案例之间证明方向不一致
- 需要临时编造历史机会才能填满模板

复刻时必须保留：

- 第1句提出利益或结果问题
- 第2句降低防备
- 第3句提出认知二选一
- 第4句用第一个案例追问
- 第5句确认上一答案并继续追问第二个案例

复刻时禁止：

- 只按关键词替换原案例
- 把连续追问改成直接讲道理
- 没有第二个案例仍强行使用这套结构
