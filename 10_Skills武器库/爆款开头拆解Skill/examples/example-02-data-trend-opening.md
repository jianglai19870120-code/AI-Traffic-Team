# 爆款开头卡片

- 开头编号：BK-SAMPLE-002
- 博主名：样板博主
- 选题：灵活就业人数变化会带来什么影响

### 1. 原文前5句

1. 我们真的要提前为自己想想出路了。
2. 前段时间我看了一份报告，说今年灵活就业人数很有可能达到3.2亿。
3. 这是什么概念呢？
4. 这个数字在2021年的时候才2亿，到了2024年年底是2.4亿。
5. 如果今年真的达到3.2亿，按照这个速度继续发展，再过两年，我们就会有一半的就业人口都是灵活就业了。

### 2. 逐句拆解

|句子|原文|核心功能|写作结构|
|-|-|-|-|
|第1句|我们真的要提前为自己想想出路了。|危机提醒|共同人群＋未来风险＋行动提醒|
|第2句|前段时间我看了一份报告，说今年灵活就业人数很有可能达到3.2亿。|数据证明|信息来源＋现实趋势＋具体预测数据|
|第3句|这是什么概念呢？|悬念追问|数据出现＋意义追问|
|第4句|这个数字在2021年的时候才2亿，到了2024年年底是2.4亿。|时间对比|过去时间与数据＋当前时间与数据＋增长对比|
|第5句|如果今年真的达到3.2亿，按照这个速度继续发展，再过两年，我们就会有一半的就业人口都是灵活就业了。|趋势推演|当前预测＋延续速度＋未来结果|

### 3. 五句推进逻辑

> 危机提醒 → 数据证明 → 悬念追问 → 时间对比 → 趋势推演

### 4. 五句结构骨架

1. 先给出一个关于个人未来的警告
2. 引用一份报告或数据，抛出异常变化
3. 追问这个数字意味着什么
4. 用过去和现在的数据进行对比
5. 按照当前速度推演未来，得出一个严重结果

句式模板：

1. 我们真的要提前为自己想想【出路／应对办法】了。
2. 前段时间我看到一份报告，说【某个群体／某种现象】在今年很有可能达到【惊人数据】。
3. 这是什么概念呢？
4. 这个数字在【过去时间】才只有【过去数据】，到了【最近时间】已经达到【当前数据】。
5. 如果今年真的达到【目标数据】，那么按照这个速度继续发展，再过【时间】，就意味着【与普通人密切相关的严重结果】。

### 5. 适合承载的论证方式

> 数据＋时间对比＋趋势推演

### 6. 调用匹配规则

适合的新正文：

> 正文核心结论依靠数据变化、时间对比或趋势推演成立。

需要具备的素材条件：

- 至少有一个当前数据
- 至少有一个过去数据或对照数据
- 数据之间存在明显变化
- 能从变化推演出一个与普通人有关的未来结果

不适合的新正文：

- 只有观点，没有数据
- 只有故事，没有趋势
- 只有方法步骤，没有时间变化
- 需要编造数据才能填满模板

复刻时必须保留：

- 第1句先给风险或提醒
- 第2句抛出数据
- 第3句追问数据含义
- 第4句做时间对比
- 第5句推演未来结果

复刻时禁止：

- 没有数据却硬写“有报告显示”
- 把数据句改成故事句
- 把趋势推演改成方法预告
