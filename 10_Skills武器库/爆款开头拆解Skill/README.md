# 爆款开头拆解Skill

这是一个可安装到 `Codex` 的正式 Skill，用来把账号级表格中的完整短视频 `文案` 拆成标准爆款开头卡片。

当前版本是“前5句切分 + 前5句分析”的合并版：

1. 先从完整文案中切出前5个口播功能句；
2. 再分析逐句核心功能；
3. 再提炼逐句写作结构；
4. 再总结五句推进逻辑；
5. 再提炼五句结构骨架和句式模板；
6. 最后判断唯一一种适合承载的论证方式，并写出调用匹配规则。

选择动作不写入原始表格。Skill 只读取独立外部选中清单，再回到账号级 `xlsx` 取原始数据。

## 本机私有模式

- 默认账号表目录：`02_资产中心/03_对标账号库`
- 默认选中清单：`02_资产中心/05_爆款开头库/00_爆款开头选中清单.md`
- 默认输出目录：`02_资产中心/05_爆款开头库`
- 原文案来源：博主对标表格中的 `文案` 字段
- 选题来源：博主对标表格中的 `视频信息` 字段

推荐运行：

```powershell
python scripts/run_baokuan_opening_breakdown.py
```

## 对外公开模式

- 输入：用户自行提供的账号级 `xlsx` 目录
- 选中清单：用户自行提供的 markdown 清单
- 输出：用户自己的爆款开头库目录

推荐运行：

```powershell
python scripts/run_baokuan_opening_breakdown.py --input-dir D:\my-inputs --selection-file D:\my-output\00_爆款开头选中清单.md --output-dir D:\my-output
```

## 输入字段

账号级 `xlsx` 必需字段：

- `视频信息`
- `点赞数`
- `文案`

账号级 `xlsx` 可选字段：

- `链接`
- `发布时间`
- `内容类型`

外部选中清单字段：

- `博主名`
- `视频信息`
- `链接`
- `状态`
- `备注`

## 输出规则

- 每个命中选题 `1` 个文件
- 每个文件 `1` 个独立 `BK` 编号
- 已存在同一 `博主名 + 选题名` 时覆盖更新，不重复占号
- 文件名格式：`BK001_博主名_选题名.md`
- 固定输出原文前5句、逐句拆解、五句推进逻辑、五句结构骨架、适合承载的论证方式、调用匹配规则

这些卡片的 `适合承载的论证方式` 和 `调用匹配规则`，是后续 `爆款开头成稿生成Skill` 选开头时的正式匹配依据。

## 安装说明

本机安装目录：

- `%USERPROFILE%\.codex\skills\爆款开头拆解Skill`

同步安装时不要带：

- `__pycache__`
- `.pyc`
- 其他运行产物
