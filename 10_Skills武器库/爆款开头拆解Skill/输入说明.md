# 爆款开头拆解Skill 输入说明

本 Skill 是“前5句切分 + 前5句分析”的合并版。输入仍是一条完整短视频文案，执行器会先切出前5个口播功能句，再生成开头卡片。

## 本机私有模式

默认账号表目录：

- `02_资产中心/03_对标账号库`

默认选中清单：

- `02_资产中心/05_爆款开头库/00_爆款开头选中清单.md`

默认输出目录：

- `02_资产中心/05_爆款开头库`

## 对外公开模式

用户自行提供：

- 账号级 `xlsx` 输入目录
- 外部选中清单 markdown 文件
- 自己的爆款开头库输出目录

公开参考：

- `02_资产中心/03_对标账号库` 中的正式账号级对标表
- `02_资产中心/05_爆款开头库/00_爆款开头选中清单.md`

## 账号表字段合同

必需字段：

- `视频信息`
- `点赞数`
- `文案`

可选字段：

- `链接`
- `发布时间`
- `内容类型`

规则：

- `文案` 是唯一正式拆解原文来源
- `视频信息` 是唯一正式选题来源
- xlsx 不可读直接报输入文件错误
- 缺 `文案` 或 `视频信息` 直接报错
- 不需要原始 xlsx 自带任何表内选择字段

## 外部选中清单合同

必需字段：

- `博主名`
- `视频信息`
- `链接`
- `状态`
- `备注`

命中规则：

- 优先按 `链接` 精确命中
- 没有 `链接` 时，按 `博主名 + 视频信息` 精确命中
- `链接` 和 `视频信息` 同时为空时，该行无效
- 同一博主表内存在多条同名 `视频信息` 时，必须补充链接，不自动猜

原始博主表不需要也不允许新增任何表内选择字段。
