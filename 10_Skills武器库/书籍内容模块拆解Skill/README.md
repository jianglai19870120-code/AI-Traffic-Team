# 书籍内容模块拆解Skill

这是整本书内容拆解的正式总入口。

它只负责把一本已经标准化并通过原始资料入库审核的书，拆成可进入干货型内容模块库的三类正式资产：

- 金句模块
- 误区模块
- 步骤模块

它不负责：

- 短视频成稿文案生成
- 对标结构拆解

固定边界：

- “拆一本书”默认走这个 Skill
- 不再暴露独立子 Skill 目录

当前正式执行入口：

- `scripts/run_book_module_breakdown.py`
- `scripts/execute_book_module_breakdown.py`
