# 爆款开头成稿生成Skill

这是“正文方案 -> 爆款开头匹配 -> 最终口播成稿”的正式入口。

输入入口：

- `02_资产中心/04_爆款选题库/00_手动输入选题表.md`

读取链路：

1. 先按 `文案结构` 去 `02_资产中心/06_生成正文库` 找正文方案
2. 再按正文真实表达方向去 `02_资产中心/05_爆款开头库` 选 `BK` 开头卡片
3. 最后把“开头 + 正文方案”一起润色成最终成稿

当前正式支持：

- `文案结构=干货型`

输出目录：

- `02_资产中心/07_润色成稿库/01_干货型成稿`

输出规则：

- 文件名：`选题_YYYY-MM-DD_HH-mm-ss.md`
- H1：与文件名主体一致
- 第二行固定写 `文案结构：干货型`
- 第三行固定写 `开头卡片编号：BKxxx`
- 后面直接输出最终成稿正文

本 Skill 不重建正文逻辑，不改开头卡片原有结构，只做匹配和成稿润色。

开头复刻规则：

- 一旦 `BK` 已匹配成功，先读该卡片的 `五句结构骨架` 和 `句式模板`
- 如果卡片已经给出五句模板，就必须逐句按模板填空复刻
- 只替换 `【】` 中的变量内容，不允许自由改句型

正文格式规则：

- 正文结构句必须整句加粗
- 当前只加粗正文结构句，不加粗开头五句
- 典型加粗位置包括：误区起手句、步骤起手句、第二组问题的结构推进句

审核规则：

- 成稿生成后，必须立刻调用小审的 `audit_final_drafts.py`
- 审核通过后，才能把手动输入选题表回写为 `成稿状态=已生成`
- 审核退回时，必须回写为 `成稿状态=退回修改`

状态字段说明：

- `正文时间 / 正文状态`：正文方案生成状态
- `成稿时间 / 成稿状态`：最终成稿生成状态
