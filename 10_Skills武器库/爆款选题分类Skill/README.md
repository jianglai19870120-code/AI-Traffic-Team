# 爆款选题分类Skill

这是小策读取对标账号 Excel、提炼选题并写入爆款选题库的正式入口。

正式能力：

- 按文件真实格式读取 `.xlsx`、`.xls` 和后缀伪装文件；
- 使用统一标题完整性规则清洗选题；
- 分类到科学创业、能力成长、赚钱财富、个人IP、AI科技或 `99` 缓冲表；
- 使用 `选中选题 / 选中开头` 双入口同步下游清单；
- 双否删除源选题行，单否只回收对应下游记录；
- 写出分类审核记录。

工作区根路径统一使用环境变量 `AI_TRAFFIC_FACTORY_ROOT`，也可以显式提供 `--root`。

```text
python scripts/classify_benchmark_topics.py --root <workspace-root>
```

兼容代码可以识别旧表头，但正式输出只使用当前双入口字段。
