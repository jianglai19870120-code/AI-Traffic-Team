## 99_其他类型的正式使用口径

`99_其他类型` 不是一个真正的内容分类，只是“待补规则缓冲区”。

因此，任何被归入 `99_其他类型` 的选题，都必须同时补一列或补一段说明：

- 当前所在缓冲表：`99_其他类型`
- 当前具体命名：必须写成具体未归类主题名
- 疑似应归类：`科学创业 / 能力成长 / 赚钱财富 / 个人IP / AI科技 / 无`
- 原因：写明命中的是哪组语义，而不是只写“暂未分类”

补充约束：

- `99_其他类型选题表.md` 仅保留为缓冲文件名
- 表格里的 `主题分类` 不允许继续写 `其他类型`
- 也不允许写 `待补规则 / 未分类 / 杂项 / 综合`
- 真正兜底时统一写 `待细化主题`

## 标题提炼的正式补充规则

- 标题清洗先判断是不是完整表达，再决定要不要压缩，不按固定字数硬截断。
- 遇到“题眼 + 解释句”结构时，优先保留前面的完整题眼，例如：
  - `为自己做事 当...` -> `为自己做事`
  - `进入"鹤群"才是正确的成长路径 人会...` -> `进入"鹤群"才是正确的成长路径`
- 遇到“完整首句 + 后续解释”结构时，优先保留完整首句，例如：
  - `永远不要"花钱"，只做投资。 投资你的大脑...` -> `永远不要"花钱"，只做投资`
- 短题不等于残句。像 `真正的好资产 / 为自己做事 / 怎么用AI挣钱` 这类完整短题，要直接保留。
- 小数或数字开头标题不能误判成编号列表，例如：
  - `1.8 万次转发，就是 1.8 万篇小作文` 不能再截成 `1.8 万次转发，就是`
- 引号、英文词、产品名、平台名属于标题语义时必须保留，不能因为 `Claude Code / Skill / 抖音` 等词被误删。
- 平台噪音只删除真正的结尾噪音，不误删标题正文里的语义词。

## 审核补充口径

- 分类判断统一基于“最终提炼后的标题”，不再基于原始长口播串直接判分类。
- 当前分类表中的标题，再次跑同一套清洗逻辑时，不应继续发生变化；如果还能继续被压缩，视为本轮仍有残留，不能判通过。

## 审核要求

- 不允许把表格分类值写成“其他类型”
- 必须先给出具体未归类主题名
- 必须明确写出“疑似应归类”的正式分类，若无则写 `无`
- 必须给出可解释的原因
- 如果确实无法判断，再写 `待细化主题`
