# 得到大脑工作纪实同步Skill

## 作用定位

本 Skill 归属小息，用于把得到大脑中的工作计时、工作复盘、工作反思、录音转写笔记同步为 AI流量团队的工作纪实原始资料。

## 固定鉴权

只允许从环境变量读取：

- `DEDAO_BRAIN_CLIENT_ID`
- `DEDAO_BRAIN_API_KEY`

不得把 API Key、Client ID 或任何真实鉴权内容写入仓库、Skill 文件、日志文件或输出结果。

## 得到大脑 OpenAPI

- Base URL：`https://openapi.biji.com/open`
- 笔记列表：`GET /api/v1/resource/note/list`
- 知识库笔记：`GET /api/v1/resource/knowledge/notes`
- 鉴权头：`Authorization: <API Key>`，不加 Bearer
- 客户端头：`X-Client-ID: <Client ID>`

## 输入

- 用户通过小姜提出同步任务
- 可选：得到大脑知识库 ID
- 可选：标签范围，例如 `工作纪实`、`工作计时`、`复盘`
- 可选：同步条数或时间范围
- 可选：`全部同步`，拉取得到大脑 OpenAPI 当前账号可返回的全部笔记

## 运行模式与输出

作者本机模式：

`02_资产中心/01_原始知识库/99_我的工作纪实`

外部用户模式：

`02_资产中心/01_原始知识库/99_我的工作纪实`

路径选择规则：

- 如果存在 `02_资产中心`，优先写入 `02_资产中心`。
- 如果不存在 `02_资产中心`，写入 `02_资产中心` 对应目录。
- 公开发布包保留正式说明和 Skill 合同；外部用户安装后可以把自己的真实资料写入 `02_资产中心` 正常链路。

每条笔记保存为独立 Markdown，至少包含：

- 得到 note_id
- 标题
- 创建时间
- 更新时间
- 标签
- 知识库
- 原文内容
- 同步时间

## 执行规则

1. 先检查环境变量是否存在，只允许输出是否为空和字符长度。
2. 如果未配置环境变量，返回小姜，不阻塞原有选题生产链路。
3. 执行前必须存在小姜正式分配记录，任务类型包含 `得到大脑全部笔记同步` 或 `得到大脑工作纪实同步`，目标 Agent 包含 `小息`。
4. 优先同步指定知识库；没有指定时，按标签或最近笔记列表同步。
5. `全部同步` 模式下必须分页拉取直到接口返回无更多数据，不受默认条数限制。
6. 已同步 note_id 不重复写入；接口返回重复 note_id 时只保留一份。
7. 如果文件名重名但 note_id 不同，必须追加 note_id 尾号，避免覆盖不同笔记。
8. 同步完成后，把入库记录交给小审审核，并刷新小姜工作台。
9. 小息不拆解、不评分、不生成选题、不生成文案。

## 公共样板规则

公共发布包只允许排除本地隐藏目录：

`02_资产中心/01_原始知识库/99_我的工作纪实`

公共样板最多 3 条，文件名和正文必须标注 `样板`。
