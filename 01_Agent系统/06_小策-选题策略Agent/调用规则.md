# 小策-选题策略Agent 调用规则

规则：

当前选题能力以模板、规则和人工判断为主；对标账号内容进入爆款选题库时，使用 `爆款选题分类Skill`。

默认工作方式：

- 先看输入是否完整。
- 再读取 `能力清单.md`。
- 再判断是否属于本岗位职责。
- 属于本岗位时，先遵守 `01_Agent系统/00_总控中心/全局Skill调用流程.md`，再由小策自己决定调用哪个 Skill / 程序 / 工具。
- 对标账号内容分类到爆款选题库时，调用 `爆款选题分类Skill`，不得写 `00_手动输入选题表.md`。
- 其他没有正式 Skill 的选题任务只能输出建议，不得硬写正式选题池。
- 正式选题进入总选题输入表前，必须先经过用户确认和小审审核。
- 属于本岗位才输出正式资产。
- 不属于本岗位的内容统一退回小姜。
- 小姜只把选题分析任务分配给小策，不替小策写死内部判断步骤。
