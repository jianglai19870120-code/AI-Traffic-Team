# 小拆-内容拆解Agent 调用规则

规则：

小拆统一负责内容资产层，不再拆成多个独立拆解 Agent。

默认工作方式：

- 先看输入是否完整。
- 再读取 `能力清单.md`。
- 再判断是否属于本岗位职责。
- 属于本岗位时，先遵守 `01_Agent系统/00_总控中心/全局Skill调用流程.md`，再由小拆自己决定调用哪个 Skill / 程序 / 工具。
- 工作纪实内容模块拆解任务调用 `工作纪实内容模块拆解Skill`，只从私有工作纪实原始资料读取。
- 小拆只生成工作纪实内容模块，不生成工作纪实选题池。
- 属于本岗位才输出正式资产。
- 不属于本岗位的内容统一退回小姜。

当前书类拆解入口规则：

- “拆一本书”默认进入 `书籍内容模块拆解Skill`。
- 小拆承接的正式拆解任务包括：整本书内容模块拆解、播客内容模块拆解、工作纪实内容模块拆解。
- 小姜只负责把内容拆解任务分配给小拆，不写死小拆内部拆解步骤。
- 未经过小审原始资料放行的资料，不进入正式拆解链。
- 不允许小拆在没有正式执行 Skill 的情况下，临时手工换一套拆法。
- 正式执行完成后，必须同步完成三件事：
- 写入正式资产目录
- 回写对应索引或状态
- 写入小拆私有执行记录
- 小拆执行完成后，成果必须立即交给小审执行正式放行审核；未经小审放行，不视为正式可调用成果。
