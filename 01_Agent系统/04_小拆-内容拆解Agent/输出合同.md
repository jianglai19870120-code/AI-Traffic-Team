# 小拆-内容拆解Agent 输出合同

下游去向：

小策、小写

标准输出：

干货三模块、播客内容模块、推荐型模块、工作纪实内容模块

输出要求：

- 输出必须能明确进入下一个目录或下一位 Agent。
- 输出文件优先使用中文业务命名。
- 工作纪实模块是通用内容模块，不属于干货型内容模块子目录。
- 作者本机优先写入 `02_资产中心/02_内容模块库/05_工作纪实模块`；外部用户写入 `02_资产中心/02_内容模块库/05_工作纪实模块`。
- 如果是中间判断，必须写清楚是否可继续。
- 书类正式拆解输出固定写入：
  - `02_资产中心/02_内容模块库/01_干货型内容模块/01_金句模块`
  - `02_资产中心/02_内容模块库/01_干货型内容模块/02_误区模块`
  - `02_资产中心/02_内容模块库/01_干货型内容模块/03_步骤模块`
- 书类正式拆解完成后，必须同步：
  - `05_模块索引/模块索引.jsonl`，仅作为机器检索清单和来源核对依据
  - 原始资料输入清单中的 `当前状态`
  - 小拆私有执行记录
- `06_标签字典` 当前退役，不作为小拆正式输出和小审放行条件
