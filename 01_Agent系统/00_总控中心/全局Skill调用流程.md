# 全局 Skill 调用流程

这份规则适用于所有 Agent。

## 固定原则

- `10_Skills武器库` 是所有 Agent 查找源 Skill 的权威目录。
- `%USERPROFILE%\.codex\skills` 是 Codex 当前可调用的安装目录。
- Agent 不能因为 Codex skills 目录里暂时没有某个 Skill，就直接判断“没有能力”。
- 只有 `10_Skills武器库` 里也没有对应 Skill，或源 Skill 没有正式执行能力，才允许退回小姜。

## Agent 接到任务后的固定顺序

0. 执行前先校验是否已有小姜正式分配记录；需要小审闭环的正式任务，没有分配记录不得执行。
1. 读取自己的 `能力清单.md`、`调用规则.md`、`输入合同.md`、`输出合同.md`。
2. 判断任务是否属于本岗位。
3. 从能力清单里确认本任务对应的 Skill 名称。
4. 优先检查 `10_Skills武器库` 是否存在同名源 Skill。
5. 如果源 Skill 存在，但 `%USERPROFILE%\.codex\skills` 未安装或版本不同，先从武器库同步安装。
6. 安装后读取该 Skill 的 `SKILL.md` 和必要脚本、说明文件。
7. 确认输入、输出、审核链路完整后再执行。
8. 执行完成后按本岗位输出合同写入资产、索引、状态和执行记录。
9. 需要审核且当前已建成审核能力的正式成果必须交给小审；小审未放行前，不视为正式可调用成果。尚未建成审核能力的成果，必须明确标记为“审核待建设”。

## 退回小姜的条件

- 本岗位能力清单没有声明能接这个任务。
- 需要小审闭环的正式任务缺少小姜正式分配记录。
- `10_Skills武器库` 中没有对应源 Skill。
- 源 Skill 只有说明，没有正式执行能力。
- 输入不满足该 Skill 的固定输入合同。
- 输出没有明确资产目录、索引或状态回写规则。
- 对于已建审核能力的正式成果，没有小审审核闭环。
