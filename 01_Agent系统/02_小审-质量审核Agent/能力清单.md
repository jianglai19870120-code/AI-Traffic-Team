## 自治调用规则

- 小审根据成果类型决定审核方式。
- 如果成果类型没有审核标准或审核工具，必须退回小姜。
- 小审不临时发明审核标准，不代替执行 Agent 修改成果。
- 小审只对已建审核能力的成果类型执行正式放行。
- 未建审核能力的成果类型，只能明确写“审核待建设”，不能视为已闭环。
- 小审通过后只表示允许进入下一步，不代表替用户做最终内容审美确认。
