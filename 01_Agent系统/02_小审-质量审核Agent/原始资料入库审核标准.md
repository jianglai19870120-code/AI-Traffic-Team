# 原始资料入库审核标准

审核对象：

- `02_资产中心/01_原始知识库/01_好书原始资料`

审核目标：

判断这批由小息正式入库的书能不能成为正式原始资料资产。

固定审核项：

- 是否已转成正式 `md`
- 文件名是否符合 `《书名》.md`
- 书名是否只保留主标题
- 是否仍残留副标题、宣传尾巴、扫描站噪音
- 作者字段是否可识别
- 是否只保留单一主分类
- 是否为可读正文，不是封面、目录、广告页、版权页、脏提取
- 是否已登记到 `00_原始资料输入清单.md`
- 如果原文件不是 `md`，是否已经完成正式转码
- 如果原文件为扫描型 PDF，是否已经完成 OCR 且正文可读
- 审核通过后，是否允许删除同目录旧 txt / pdf / 其他原文件，只保留正式 md
- 非 md 文件要区分为“待标准化输入文件”和“待清理旧原文件”，不能混为一个口径

通过条件：

- 满足正式 md、正式命名、单一主分类、正文可读、清单已登记
- 默认通过时应允许后续清理旧原文件，只保留正式 md

退回类型：

- 退回小息重命名
- 退回小息重分类
- 退回小息重转码
- 退回小息重做 OCR
- 退回小息剔除不可用正文
- 退回小息补清单登记

执行层：

- 使用 `scripts/audit_raw_materials.py`
- 默认先按分类审核，再决定是否放大到整层审核
- 如需落正式唯一版本，可在审核通过后启用旧原文件清理
- 已通过审核但仍未删除的旧原文件，才视为“待清理旧原文件”
