# 爆款选题分类审核标准

## 审核目标

小审负责审核 `爆款选题分类Skill` 生成的爆款选题分类表，重点防止字段结构错误、公私层写错、选题提取越界和主题分类明显跑偏。

## 必审字段

- 选题
- 主题分类
- 博主名
- 点赞数
- 链接
- 发布时间
- 是否选用

## 审核标准

### 选题提取

- 选题只能来自账号表 `视频信息` 列。
- `#` 后内容视为话题标签，不得进入选题。
- `视频信息` 超过 30 个字时，只允许按第一句、短句或前 30 字提炼，不允许读取 `文案` 再总结。
- `视频信息` 为空的记录不得写入分类表，必须进入审核报告。

### 字段结构

- 六张分类表字段必须完全一致。
- 不允许出现旧的状态字段、备注字段或表内选择字段。
- `是否选用` 默认留空，供用户人工填写，脚本不得自动写值。

### 主题分类

- 分类固定为：科学创业、能力成长、赚钱财富、个人IP、AI科技、其他类型。
- 分类要按选题的主要承诺判断，不按单个关键词抢占。
- 信息不足、多类冲突或无法判断主承诺的记录，必须进入 `99_其他类型选题表.md`。

### 公私层

- 作者本机真实分类表必须写入 `02_资产中心/04_爆款选题库`。
- 公共层 `02_资产中心/04_爆款选题库` 只允许保留 README 和样板表。
- 公共层不得出现真实账号数据、真实链接批量表或真实私域选题。

## 回退规则

- 字段缺失、字段顺序错误或出现旧字段，退回小策修正。
- 选题读取了 `文案` 或保留了 `#` 后话题标签，退回小策重跑。
- `是否选用` 被自动填写，退回小策清空并重跑。
- 公共层出现真实数据，退回小姜处理公私层错误。
