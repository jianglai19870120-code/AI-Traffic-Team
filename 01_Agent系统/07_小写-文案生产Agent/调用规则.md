# 小写-文案生产Agent 调用规则

规则：

推荐型文案生成先留空接口，不伪造当前不存在的正式 Skill。

默认工作方式：

- 先看输入是否完整。
- 再读取 `能力清单.md`。
- 再判断是否属于本岗位职责。
- 属于本岗位时，先遵守 `01_Agent系统/00_总控中心/全局Skill调用流程.md`，再由小写自己决定调用哪个 Skill / 程序 / 工具。
- 真实干货文案生产默认写入 `02_资产中心/06_生成正文库` 和 `02_资产中心/07_润色成稿库`。
- 使用工作纪实时，开头优先从“我最近经历了什么事”切入，再沿用干货解决方案框架。
- 正式主链中的真实模块和正式产物可以直接作为生产素材；只有本地隐藏目录不进入公开链。
- 属于本岗位才输出正式资产。
- 不属于本岗位的内容统一退回小姜。
- 小姜只把文案生产任务分配给小写，不替小写写死内部调用步骤。
