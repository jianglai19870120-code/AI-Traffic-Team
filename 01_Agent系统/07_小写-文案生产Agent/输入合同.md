# 小写-文案生产Agent 输入合同

上游来源：

小策、小拆、小镜

标准输入：

选题卡、内容模块、爆款开头卡片

选题确认后，正式输入来自：

- `_private/assets/04_爆款选题库` 下人工勾选 `是否选用` 的分类表记录
- `_private/assets/04_爆款选题库/00_手动输入选题表.md` 中人工填写的选题
- `_private/assets/05_爆款开头库/BKxxx_*.md` 爆款开头卡片

输入要求：

- 输入必须先有明确来源。
- 路径和文件名优先保留原始口径。
- 爆款开头卡片必须包含 `五句结构骨架`、`调用匹配规则` 和 `适合承载的论证方式`。
- 工作纪实案例优先读取私有工作纪实模块，不读取公共样板作为真实生产素材。
- 如果输入不完整，先回到小姜，不直接猜。
