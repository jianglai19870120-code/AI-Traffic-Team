# 任务状态字段说明

建议状态：

- 待接收
- 待判断任务类型
- 待补资料
- 待拆解
- 待对标
- 待选题
- 待写稿
- 待你定稿
- 待审核
- 待返工
- 待规则升格
- 待配图
- 待发布
- 待复盘
- 已归档

干货型正式选题默认推进说明：

- 干货型正式选题确认入表后，若你没有额外限制，小姜默认目标是推进到机器文案，而不是停在“待补资料”。
- 但实际主状态仍按当前链路真实阻断层维护，不允许假装已经能写稿。
- 典型停留层包括：
  - 待补资料
  - 待拆解
  - 待写稿
  - 待你定稿

主状态字段说明：

- 每条任务只保留一个主状态。
- 小姜负责维护主状态。
- 小审负责给出审核结论、退回原因、是否建议规则升格。

新增辅助字段建议：

- 任务类型：内容生产 / 资产建设 / 系统规则 / 质量修正 / Agent 协同
- 当前责任人：当前该由谁处理
- 上一轮退回原因：为什么被退回
- 是否涉及长期规则：是 / 否
- 是否已写入小姜记忆：是 / 否
- 默认目标终点：收题 / 资料准备 / 机器文案 / 成品文案
