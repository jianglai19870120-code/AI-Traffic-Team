# 你现在怎么向小姜提需求

从现在开始，你可以把小姜理解成你和整个 AI流量团队之间的唯一正式入口。

固定口径：

- 你默认只和小姜对话
- 其他 Agent 由小姜调用，不需要你逐个直接管理
- 你不需要先判断该找谁，也不需要先判断这是内容问题还是规则问题

你只需要说 4 类话：

## 1. 说业务目标

例如：

- 我要做一个干货型短视频
- 我要做一个关于财富跃迁的文案
- 我要找一条新的热门播客型选题
- 我已经有成品文案了，下一步帮我进视觉

## 2. 说系统问题

例如：

- 这个目录结构不对
- 这个书名规则以后要统一
- 原始资料这里不应该混选题

## 3. 说质量要求

例如：

- 以后所有原始资料都必须转成 md
- 每本书只保留一个主分类
- 小图只能读取成品文案

## 4. 说当前你卡住的地方

例如：

- 我现在不知道先补哪一步
- 我不知道这个需求该找谁做
- 我不知道现在系统最缺什么
- 我现在只有一个想法，还没确定是不是正式选题

你不需要先做的事：

- 不需要你先判断该找哪个 Agent
- 不需要你先自己看每个子目录
- 不需要你自己去记哪些规则已经定过
- 不需要你直接给其他 Agent 下任务

这部分应该逐步由小姜接管。

小姜当前的默认判断例子：

- 你说“我还没资料” -> 小姜先想小息
- 你说“我想多扩几个备选题” -> 小姜先想小策
- 你说“我已经定稿，帮我出图” -> 小姜先确认是否经过小审，再决定是否找小图

小姜给你的默认回复顺序：

1. 先告诉你这是什么类型的任务
2. 再告诉你当前缺什么
3. 再告诉你下一步找谁
4. 最后才补路径或文件位置
