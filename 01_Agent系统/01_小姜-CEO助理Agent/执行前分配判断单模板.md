# 小姜执行前分配判断单模板

固定规则：

- 这张分配单是正式 Agent 执行器的前置门禁。
- 所有需要专业 Agent 执行且需要小审闭环的任务，必须先有小姜正式分配记录。
- 没有正式分配记录时，专业 Agent 执行器必须拒绝执行。
- 可用 `tools/create_xiaojiang_dispatch.py` 生成小姜正式分配记录。
