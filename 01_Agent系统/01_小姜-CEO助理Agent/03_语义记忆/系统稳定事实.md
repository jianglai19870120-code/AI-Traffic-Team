# 小姜语义记忆：系统稳定事实

## 主入口事实

- 你未来默认只和小姜对话。
- 小姜目录下的 `00_小姜工作台.md` 是“我接下来还有什么要做”的唯一正式总览入口。
- 其他 Agent 是小姜调用的专业员工，不是你逐个直接管理的对象。
- 你后续单独回复 `1` 时，小姜默认理解为“确认继续 / 确认执行”。

## 资产中心事实

- 原始知识库只放原始输入资料。
- 内容模块库只放拆解后的模块资产。
- 对标账号库只放账号级对标表和字段模板。
- 爆款选题库只放从对标账号库提取并分类后的选题表。
- 爆款开头库只放外部选中清单、爆款开头卡片和公开样板。
- 视觉库只放视觉结果，不放正文文案。
- 复盘库当前先按“我的账号复盘 / 对标账号复盘”分层。

## 工作流事实

- 当前优先跑通的是短视频主链路。
- 当前第一次正式承接重点是干货型链路。
- 爆款选题自动分类的正式落点是 `_private/assets/04_爆款选题库`；公开层只保留样板表。
- `00_手动输入选题表.md` 是私域人工选择入口，不由自动分类 Skill 写入。
- 选题被人工确认后，小姜再判断是否继续沿干货或播客文案链路推进到机器文案。
- 干货型正式选题不能跳过小息书源筛选直接生成文案。
- 每条干货型正式选题必须先由小息检查电子书来料区是否更新，再从正式书源目录筛出 10 本候选书。
- 10 本候选书中至少 5 本完成正式干货模块拆解，才允许继续进入机器文案生成。
- 每一步正式分配前，都必须先确认这一层已有对应审核标准。
- 每一步正式执行后，能否进入下一步，统一回到小审判断。
- 小图前必须先有成品文案。
- 所有正式放行都要经过小审。

## 路径事实

- `_private/00_外部来料区/电子书` 现在只是你本机的外部来料区。
- 小审真实审核记录统一进入 `_private/agent_records/02_小审-质量审核Agent/审核记录`。
- 仓库内正式依赖改为小息工作区下的干货书源目录。
- `_private/` 是作者本地私有层，不进入 GitHub 公开发布包。
- 外部用户安装后默认不使用 `_private/`，他们直接把自己的资料、模块、文案、视觉结果写入正常链路目录。
- 公开发布包只保留结构、模板、规则、Skill、工具和脱敏样板，不保留作者真实业务资产。
- 旧三条线目录只作为历史来源，不再作为新根层公开文档、Skill 文档和工具脚本里的正式依赖路径。
- 公开层不保留历史迁移脚本、Skill 历史 outputs、`.tmp`、`__pycache__` 等运行产物。

## Agent 事实

- 小息负责信息采集与正式入库。
- 小息处理干货书源时，固定区分目录刷新模式和选题入库模式。
- 小息处理干货型正式选题时，必须输出 10 本候选书及其入库 / 拆解状态。
- 小拆负责把原始资料沉淀成内容模块。
- 小镜负责对标结构研究。
- 小策负责爆款选题主题分类和选题策略判断，不再调用退役总选题入口。
- 小写负责机器文案生成。
- 你负责机器文案到成品文案的手动定稿。
- 小图只读取成品文案，并且默认只在小审放行后进入视觉阶段。
- 小审负责质量放行和规则升格。
- 小数负责内容复盘。
