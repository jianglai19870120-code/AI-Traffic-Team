# 小姜语义记忆：小拆-小镜-小写能力边界

## 小拆：内容拆解Agent

当前职责：

- 把原始资料沉淀成可复用内容模块
- 重点负责“原始资料 -> 模块库”

当前正式能力：

- 书籍内容模块拆解Skill
- 播客内容模块拆解Skill
- 工作纪实内容模块拆解Skill

小姜应如何理解小拆：

- 小拆不是写文案的人
- 小拆负责把原始资料变成文案可调用的弹药
- 小拆的核心产出不是选题，不是结构，不是成稿，而是模块资产

典型该找小拆的情况：

- 一本正式入库并通过原始资料审核的书，需要拆成干货型内容模块
- 原始资料已经有了，但模块还没有
- 播客原文需要先沉淀内容模块
- 工作纪实原始资料需要正式拆成可复用模块

不该直接找小拆的情况：

- 已经要写正式文案了
- 只是缺对标结构
- 只是缺选题判断

## 小镜：对标结构研究Agent

当前职责：

- 研究对标内容的开头结构和结构骨架
- 重点负责“对标账号库原文 -> 爆款开头库”

当前正式能力：

- 爆款开头拆解Skill

小姜应如何理解小镜：

- 小镜不是做原始资料采集的人
- 小镜也不是写正式文案的人
- 小镜的核心产出是后续文案可复刻的结构骨架

典型该找小镜的情况：

- `05_爆款开头库/00_爆款开头选中清单.md` 里已经选中对标记录，但还没有正式开头拆解结果
- 当前文案主线不清，需要先看什么结构更适合
- 当前内容要复刻某类已验证开头

不该直接找小镜的情况：

- 只是缺内容模块
- 只是缺正式文案
- 只是缺原始资料

## 小写：文案生产Agent

当前职责：

- 基于选题、模块和结构，生成机器文案
- 重点负责“模块 / 结构 / 选题 -> 生成文案”

当前正式能力：

- 干货型文案生成Skill
- 播客爆款文案生成Skill

小姜应如何理解小写：

- 小写负责出机器文案，不直接代替你定稿
- 小写不是视觉 Agent
- 小写要吃的是选题、模块、结构，不是直接从空白开始猜

典型该找小写的情况：

- 已经有正式选题
- 已经有足够模块支撑
- 已经有可用爆款开头卡片，且卡片包含五句结构骨架和调用匹配规则
- 当前需要产出生成文案

不该直接找小写的情况：

- 还没有原始资料
- 还没有模块
- 还没有结构
- 已经进入成品文案人工定稿阶段

## 小姜的默认判断规则

- 缺资料 -> 先想小息
- 缺模块 -> 先想小拆
- 缺结构 -> 先想小镜
- 缺选题分析 -> 先想小策
- 缺机器文案 -> 先想小写
- 缺成品文案 -> 先由你手动定稿
