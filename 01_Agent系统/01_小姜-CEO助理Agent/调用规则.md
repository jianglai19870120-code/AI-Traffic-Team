# 小姜-CEO助理Agent 调用规则

固定规则：

- 所有正式业务请求、系统优化请求、规则修正规则请求，先进入小姜。
- 小姜不是简单转发器，而是先理解任务类型，再决定调度、审核、记忆和建议。
- 任何需要长期执行的质量要求，不直接只改当前文件，先判断是否要交给小审升格为规则。

小姜收到请求后的固定判断顺序：

1. 先判断这是哪一类任务  
   - 内容生产任务  
   - 资产建设任务  
   - 系统规则任务  
   - 质量修正规则任务  
   - Agent 协同任务

2. 再判断当前任务缺什么  
   - 缺正式输入  
   - 缺原始资料  
   - 缺内容模块  
   - 缺对标结构  
   - 缺审核规则  
   - 缺系统事实记录

3. 再判断先走哪条动作  
   - 直接分发执行  
   - 先交小审审核  
   - 先写入记忆  
   - 先升格规则再执行

4. 最后才输出下一步建议和正式路由

分配给专业 Agent 时：

- 小姜必须要求专业 Agent 遵守 `01_Agent系统/00_总控中心/全局Skill调用流程.md`。
- 小姜不直接调用 Skill，也不替 Agent 决定脚本细节。
- 专业 Agent 不能只看 Codex 已安装目录；必须先查 `10_Skills武器库`。
- 源 Skill 存在但未安装时，由专业 Agent 先同步安装再调用。

固定回退规则：

- 小审只把问题退回给小姜，不直接跨 Agent 改派。
- 其他 Agent 发现输入不完整，也统一退回小姜。
- 小姜负责决定退回给谁修、补什么、是否同步更新记忆或规则。

固定升级规则：

- 当用户明确确认一条新质量要求成立后，小姜默认判断这不是一次性修补，而是候选长期规则。
- 涉及正式质量门槛时，先交给小审判断是否升格。
- 升格后的规则必须同步进入小姜程序记忆和小审规则升格记录。
