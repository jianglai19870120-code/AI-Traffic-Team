# 对标账号数据

用途：保存对标账号、同行账号、竞品账号导出的短视频 CSV 数据样板。

公共层只保留目录、说明、字段模板和最多 3 条脱敏样板，不保存真实账号 CSV。

作者本机真实对标账号表默认写入：

`_private/assets/03_对标账号库`

外部用户安装 Skill 时，不需要使用 `_private`。

对外公开模式的推荐方式是：

- 自己准备一个账号级 `xlsx` 输入目录
- 按 `字段模板.md` 补齐字段
- 通过 Skill 的 `--input-dir` 参数传入

当前团队框架下，小策不直接读取原始账号表。

`参考案例/` 提供 3 个强脱敏账号字段案例，不对应真实私域记录。
