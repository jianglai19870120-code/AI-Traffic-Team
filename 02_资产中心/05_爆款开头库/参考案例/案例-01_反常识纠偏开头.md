# 案例-01_反常识纠偏开头

> 公开脱敏参考案例，不对应真实私域记录。

- 开头编号：案例-BK001
- 博主名：样板博主A
- 选题：普通人做内容，为什么不是先学技巧

### 1. 原文前5句

1. 普通人做内容，最不该先学技巧。
2. 因为技巧解决的是表达问题。
3. 但你真正卡住的，往往是判断问题。
4. 你不知道什么内容值得讲。
5. 所以后面学再多剪辑和标题，也很难稳定出结果。

### 2. 逐句拆解

|句子|原文|核心功能|写作结构|
|-|-|-|-|
|第1句|普通人做内容，最不该先学技巧。|反常识判断|目标人群＋常见动作＋直接否定|
|第2句|因为技巧解决的是表达问题。|原因解释|旧方法＋适用范围＋限定说明|
|第3句|但你真正卡住的，往往是判断问题。|问题定义|转折＋真实阻塞＋重新定义|
|第4句|你不知道什么内容值得讲。|痛点描述|用户行为＋核心困境|
|第5句|所以后面学再多剪辑和标题，也很难稳定出结果。|结果推演|继续投入＋错误方向＋无稳定结果|

### 3. 五句推进逻辑

> 反常识判断 → 原因解释 → 问题定义 → 痛点描述 → 结果推演

### 4. 五句结构骨架

1. 先否定一个常见动作
2. 说明这个动作只能解决局部问题
3. 转向真正的问题
4. 点出用户的具体困境
5. 推演继续沿旧方向做的结果

句式模板：

1. 【目标人群】做【事情】，最不该先【常见动作】。
2. 因为【常见动作】解决的是【局部问题】。
3. 但你真正卡住的，往往是【真实问题】。
4. 你不知道【具体困境】。
5. 所以后面学再多【旧方向动作】，也很难【目标结果】。

### 5. 适合承载的论证方式

> 旧认知＋直接纠偏

### 6. 调用匹配规则

适合的新正文：

> 正文需要推翻一个常见动作或旧认知，并解释真正的问题所在。

需要具备的素材条件：

- 有一个明确旧动作
- 有一个真正问题定义
- 正文能解释为什么旧动作无效

不适合的新正文：

- 只有步骤清单
- 没有认知冲突
- 不能解释为什么旧认知错

复刻时必须保留：

- 第1句直接否定旧动作
- 第3句重新定义问题
- 第5句承接正文继续解释

复刻时禁止：

- 把纠偏写成普通建议
- 编造正文没有的失败结果
