# 案例-02_数据推演开头

> 公开脱敏参考案例，不对应真实私域记录。

- 开头编号：案例-BK002
- 博主名：样板博主B
- 选题：为什么要提前准备自己的第二能力

### 1. 原文前5句

1. 我们真的要提前为自己准备第二能力了。
2. 前段时间我看到一份报告，说未来几年复合型岗位需求可能会明显增加。
3. 这是什么概念呢？
4. 过去很多岗位只需要单一技能，现在越来越多岗位要求你同时懂业务、内容和工具。
5. 如果这个趋势继续下去，再过几年，只会做单一执行的人，机会会越来越少。

### 2. 逐句拆解

|句子|原文|核心功能|写作结构|
|-|-|-|-|
|第1句|我们真的要提前为自己准备第二能力了。|危机提醒|共同人群＋未来风险＋行动提醒|
|第2句|前段时间我看到一份报告，说未来几年复合型岗位需求可能会明显增加。|数据引入|信息来源＋趋势变化＋预测方向|
|第3句|这是什么概念呢？|悬念追问|数据出现＋意义追问|
|第4句|过去很多岗位只需要单一技能，现在越来越多岗位要求你同时懂业务、内容和工具。|时间对比|过去状态＋现在变化＋能力要求|
|第5句|如果这个趋势继续下去，再过几年，只会做单一执行的人，机会会越来越少。|趋势推演|趋势延续＋未来时间＋个人后果|

### 3. 五句推进逻辑

> 危机提醒 → 数据引入 → 悬念追问 → 时间对比 → 趋势推演

### 4. 五句结构骨架

1. 先给出一个关于个人未来的警告
2. 引用一份报告或趋势信号，抛出异常变化
3. 追问这个变化意味着什么
4. 用过去和现在进行对比
5. 按照当前速度推演未来，得出一个严重结果

句式模板：

1. 我们真的要提前为自己准备【应对动作】了。
2. 前段时间我看到一份报告，说【某个趋势】未来可能会【异常变化】。
3. 这是什么概念呢？
4. 过去【旧状态】，现在【新状态】。
5. 如果这个趋势继续下去，再过【时间】，就意味着【与普通人有关的后果】。

### 5. 适合承载的论证方式

> 数据＋时间对比＋趋势推演

### 6. 调用匹配规则

适合的新正文：

> 正文核心结论依靠数据变化、时间对比或趋势推演成立。

需要具备的素材条件：

- 至少有一个趋势信号
- 有过去和现在的对比
- 能推演出普通人的未来处境

不适合的新正文：

- 只有观点，没有趋势证据
- 只有故事，没有时间变化
- 需要编造数据才能填满模板

复刻时必须保留：

- 第1句先给风险提醒
- 第3句保留意义追问
- 第5句推演未来结果

复刻时禁止：

- 没有趋势证据却硬写报告
- 把趋势推演改成方法清单
