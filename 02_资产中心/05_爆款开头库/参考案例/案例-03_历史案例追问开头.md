# 案例-03_历史案例追问开头

> 公开脱敏参考案例，不对应真实私域记录。

- 开头编号：案例-BK003
- 博主名：样板博主C
- 选题：为什么普通人要抓住新工具红利

### 1. 原文前5句

1. 如果你想在接下来几年提升自己的收入，有哪些现实机会？
2. 这条视频我简单分享一下。
3. 我先问你个问题，你觉得普通人逆袭主要靠努力，还是靠选对机会？
4. 比如说，如果你很早就开始做内容，你觉得有没有机会拿到第一波流量？
5. 有，那如果你很早就学会使用 AI 工具，是不是也更容易放大自己的效率？

### 2. 逐句拆解

|句子|原文|核心功能|写作结构|
|-|-|-|-|
|第1句|如果你想在接下来几年提升自己的收入，有哪些现实机会？|利益承诺|明确时间＋具体结果＋机会预告|
|第2句|这条视频我简单分享一下。|降低防备|弱化说教＋聊天式预告|
|第3句|我先问你个问题，你觉得普通人逆袭主要靠努力，还是靠选对机会？|认知提问|目标结果＋两个认知选项＋直接提问|
|第4句|比如说，如果你很早就开始做内容，你觉得有没有机会拿到第一波流量？|案例引入|历史节点＋具体机会＋结果追问|
|第5句|有，那如果你很早就学会使用 AI 工具，是不是也更容易放大自己的效率？|连续确认|确认上一答案＋第二机会＋继续追问|

### 3. 五句推进逻辑

> 利益承诺 → 降低防备 → 认知提问 → 案例引入 → 连续确认

### 4. 五句结构骨架

1. 先提出一个和当下有关的利益问题
2. 降低用户防备，说明只是简单分享
3. 抛出一个认知二选一问题
4. 用第一个历史或现实案例追问
5. 确认上一答案，再抛出第二个同方向案例

句式模板：

1. 如果你想在【时间范围】获得【具体结果】，有哪些【机会或方法】？
2. 这条视频我简单分享一下。
3. 我先问你个问题，你觉得【目标结果】主要靠【选项A】，还是靠【选项B】？
4. 比如说，如果你在【时间节点1】做了【事情1】，你觉得能不能【获得结果】？
5. 【确认答案】，那如果你在【时间节点2】做了【事情2】，是不是也能【获得结果】？

### 5. 适合承载的论证方式

> 历史案例＋连续追问

### 6. 调用匹配规则

适合的新正文：

> 正文需要用多个历史机会或现实案例证明一个共同结论。

需要具备的素材条件：

- 至少两个同方向案例
- 案例能共同证明正文核心结论
- 案例适合用提问方式让观众连续确认

不适合的新正文：

- 只有单个案例
- 只有方法步骤
- 案例之间证明方向不一致

复刻时必须保留：

- 第3句的二选一认知问题
- 第4句和第5句的连续追问
- 案例递进方向一致

复刻时禁止：

- 只按关键词替换案例
- 编造正文没有的历史案例
