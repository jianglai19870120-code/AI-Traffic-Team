# 爆款开头库

这里是统一后的公开爆款开头卡片资产层。

只保留：

- 目录结构
- 输入要求说明
- 选中清单模板
- 输出样板
- 模板说明

不保留：

- 真实对标账号 xlsx
- 真实对标原文
- 真实爆款开头卡片结果

作者本机真实链路默认使用：

- 账号表目录：`02_资产中心/03_对标账号库`
- 选中清单：`02_资产中心/05_爆款开头库/00_爆款开头选中清单.md`
- 输出目录：`02_资产中心/05_爆款开头库`

正式输入关系：

- 原文案来自账号表 `文案` 列
- 选题来自账号表 `视频信息` 列
- 选中动作来自外部选中清单，不来自原始表内字段

当前正式下游是：

- `干货型文案生成Skill`
- `播客爆款文案生成Skill`

当前正式产物是：

- 带独立 `BK` 编号的开头卡片
- 每个选题 1 个文件
- 固定包含前5句话、逐句拆解、五句推进逻辑、适合承载的论证方式

对外公开模式下：

- 输入目录由用户自己提供
- 选中清单由用户自己提供
- 输出目录由用户自己指定
- 当前这里保留正式开头卡片主链、说明、模板和样板卡片

`参考案例/` 提供 3 个强脱敏开头卡片案例，用于演示不同论证方式下的五句结构骨架和调用匹配规则。
