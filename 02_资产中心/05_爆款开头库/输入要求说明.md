# 爆款开头库 输入要求说明

正式输入不在公开层填写。

## 作者本机模式

- 默认账号表目录：`02_资产中心/03_对标账号库`
- 默认选中清单：`02_资产中心/05_爆款开头库/00_爆款开头选中清单.md`
- 默认输出目录：`02_资产中心/05_爆款开头库`

## 外部用户模式

- 用户自行准备账号级 `xlsx` 输入目录
- 用户自行准备外部选中清单 markdown 文件
- 用户自行准备爆款开头库输出目录
- 通过执行器参数传入：
  - `--input-dir`
  - `--selection-file`
  - `--output-dir`

## 账号表字段合同

- 必需字段：`视频信息`、`点赞数`、`文案`
- 可选字段：`链接`、`发布时间`、`内容类型`
- `文案` 是唯一正式拆解原文来源
- `视频信息` 是唯一正式选题来源

## 外部选中清单字段合同

- 必需字段：`博主名`、`视频信息`、`链接`、`状态`、`备注`
- 优先按 `链接` 精确命中
- 没有 `链接` 时，按 `博主名 + 视频信息` 精确命中
- 同一博主表内存在同名 `视频信息` 时，必须补充链接

公开层不保存真实输入数据。
