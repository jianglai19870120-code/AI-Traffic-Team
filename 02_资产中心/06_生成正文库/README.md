# 06_生成正文库

这里是机器生成正文的公开结构说明。

公开层只保留目录规则、输出模板和脱敏参考案例，不保存作者真实生成文案。

## 正式私域路径

- 作者本机干货型机器正文：`_private/assets/06_生成正文库/01_干货型文案`

## 命名规则

生成文件按文案结构进入对应子目录，不直接平铺在 `06_生成正文库` 根目录。

干货型文件名固定为：

`选题_YYYY-MM-DD_HH-mm-ss.md`

## 干货型正文固定结构

干货型正文只生成一条主线和一张四列表。

文件内部固定包含：

- H1：与文件名主体一致
- `文案结构：干货型`
- `主线`
- `序号 / 逻辑关系 / 选用模块 / 对应来源` 四列表

表格固定 11 行：

- 误区1
- 误区2
- 过渡句
- 步骤1
- 步骤2
- 步骤3
- 过渡句
- 步骤1
- 步骤2
- 步骤3
- 金句收口

其中第一组 `步骤1/2/3` 解决一个具体问题，第二组 `步骤1/2/3` 解决另一个具体问题，两组问题之间必须递进。

## 公开规则

- 不放真实选题。
- 不放真实模块正文。
- 不放真实生成文案。
- 不放真实 Obsidian 私域路径。
