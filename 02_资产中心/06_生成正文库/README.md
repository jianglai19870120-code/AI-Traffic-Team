# 06_生成正文库

这里是机器生成正文的正式资产目录说明。

## 正式路径

- 作者本机干货型机器正文：`02_资产中心/06_生成正文库/01_干货型文案`

## 命名规则

生成文件按文案结构进入对应子目录，不直接平铺在 `06_生成正文库` 根目录。

干货型文件名固定为：

`选题_YYYY-MM-DD_HH-mm-ss.md`

## 干货型正文固定结构

干货型正文只生成一条主线和一张四列表。

文件内部固定包含：

- H1：与文件名主体一致
- `文案结构：干货型`
- `主线`
- `序号 / 逻辑关系 / 选用模块 / 对应来源` 四列表

表格固定 11 行：

- 误区1
- 误区2
- 过渡句
- 步骤1
- 步骤2
- 步骤3
- 过渡句
- 步骤1
- 步骤2
- 步骤3
- 金句收口

其中第一组 `步骤1/2/3` 解决一个具体问题，第二组 `步骤1/2/3` 解决另一个具体问题，两组问题之间必须递进。

## 使用规则

- 正文方案按实际生成结果直接落库。
- 文件结构以这里的正式目录和字段说明为准。
- 不在这里重复维护第二套示例层。
