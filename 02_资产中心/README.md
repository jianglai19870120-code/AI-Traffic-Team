# 资产中心

这里是 AI流量团队 的正式资产主链。

当前正式资产库：

- `01_原始知识库`：原始输入资料、输入清单和原始资料说明
- `02_内容模块库`：书籍模块、播客观点模块、工作纪实模块和模块索引
- `03_对标账号库`：账号级对标表和字段说明
- `04_爆款选题库`：分类选题表和手动输入选题表
- `05_爆款开头库`：爆款开头选中清单和 `BK` 开头卡片
- `06_生成正文库`：正文方案正式产物
- `07_润色成稿库`：最终口播成稿正式产物
- `08_视觉配图库`：视觉配图正式产物

这里默认承载真实正式内容，不再维护第二套示例层。

本地隐藏目录只保留少量不公开内容：

- `01_原始知识库/99_我的工作纪实`
- `02_内容模块库/99_工作纪实模块`
- Agent 运行记录目录
- 工作流运行记录目录

公开发布规则：

- GitHub 默认同步正式主链
- 只有本地隐藏目录不会进入公开发布包
- 新增或调整资产库时，必须同步检查 `.gitignore` 和发布脚本排除规则
