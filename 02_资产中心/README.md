# 资产中心

这里是 AI流量团队 的正式资产主链。

这里直接承载正式资产、说明、字段模板、样板、参考案例，以及允许公开的真实业务资产。

当前正式资产库：

- `01_原始知识库`：原始输入资料的公开结构、说明和模板。
- `02_内容模块库`：内容模块库的公开结构、说明和样板。
- `03_对标账号库`：账号级对标表、字段模板和样板。
- `04_爆款选题库`：爆款选题分类表、手动输入表和样板。
- `05_爆款开头库`：爆款开头选中清单、开头卡片和样板。
- `06_生成正文库`：机器生成正文方案、命名规则和样板。
- `07_润色成稿库`：最终口播成稿、字段说明和样板。

每个正式库下都可以保留真实业务资产。需要隐藏的内容，不再放到 `_private`，而是放进本地隐藏目录，并由 `.gitignore` 和发布脚本双重排除。

说明：

- 当前公开主链只锁定 `01~07` 七个正式资产库。
- 旧视觉库与旧复盘库不再属于当前现役公开主链。
- 如果后续继续公开视觉或复盘能力，应按新编号单独重建为 `08_视觉库`、`09_复盘库`。

本地隐藏目录：

- `01_原始知识库/99_我的工作纪实`
- `02_内容模块库/99_工作纪实模块`
- Agent 运行记录目录
- 工作流运行记录目录

公开发布规则：

- GitHub 默认发布真实主链内容。
- 只有本地隐藏目录不会进入公开发布包。
- 新增或调整资产库时，必须同步检查 `.gitignore` 和发布脚本排除规则。
