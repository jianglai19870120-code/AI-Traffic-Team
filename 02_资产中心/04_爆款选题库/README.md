# 爆款选题库

这里是爆款选题分类表和正文入口选中清单的正式主链目录。

正式数据由 `爆款选题分类Skill` 从账号级对标表中提取，直接进入主链目录。

分类表字段统一为：

| 选题 | 主题分类 | 博主名 | 点赞数 | 链接 | 发布时间 | 选中选题 | 选中开头 |
|---|---|---|---:|---|---|---|---|

分类固定为：

- 科学创业
- 能力成长
- 赚钱财富
- 个人IP
- AI科技
- 其他类型

`00_爆款选题选中清单.md` 是正文入口选中清单，由自动分类 Skill 根据 `选中选题` 同步写入。

`00_爆款选题选中清单.md` 字段固定为：

| 序号 | 文案结构 | 选题 | 链接 | 正文时间 | 正文状态 | 成稿时间 | 成稿状态 | 视觉时间 | 视觉状态 |
|---|---|---|---|---|---|---|---|---|---|

其中：

- `文案结构`：默认留空，等待手工填写
- `链接`：回指原始账号表视频链接
- `正文时间 / 正文状态`：正文方案生成状态
- `成稿时间 / 成稿状态`：最终成稿生成状态
- `视觉时间 / 视觉状态`：视觉配图生成状态
